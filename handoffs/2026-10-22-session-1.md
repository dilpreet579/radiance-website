## Decisions and gotchas worth knowing

- Routes: scanner is `/admin/scan` (shares `/admin/login` and the `admins` table; roles `super`/`scanner`). Offered to move it to a top-level `/scan`; user hadn't decided.
- Design departures: admin cards need a Save click (design autosaved); login page has no role tabs (role comes from DB); "Demo scans" omitted.
- `register_student` takes an advisory lock, so seat caps and duplicates are race-safe. Duplicate = same email OR last-10-digit phone OR roll (case-insensitive).
- Public pages use ISR (`revalidate = 60`), so admin edits can take ~1–2 reloads to show (admin actions also `revalidatePath`).
- `next.config.ts`: removed the scaffold's `cacheComponents`/`partialPrefetching` (incompatible with `revalidate`); `serverActions.bodySizeLimit` is 5mb for logo uploads. `sharp` is a direct dependency.
- Competitions page: empty `competitions` table → placeholder competitions; adding the first real one replaces all placeholders.
- Contact/social in `CONTACT` (`lib/content.ts`): clairvoyance@nitdelhi.ac.in + Instagram/YouTube/LinkedIn (LinkedIn URL returned 999 to curl, unverified).
- Comedian is **Vaibhav Karn** (PLAN.md still says Kant; PLAN.md left as the original spec). Channel is **Motion Nations** (plural).
